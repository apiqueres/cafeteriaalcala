# Cafetería Alcalá · Cullera

Sitio web estático de la Cafetería Alcalá (Cullera, Valencia): inicio, carta, reservas y contacto.

- Sin dependencias ni proceso de build: HTML, CSS y JavaScript planos.
- Los datos de la carta están en `js/menu-data.js`.
- Publicado con GitHub Pages desde la rama `main` (carpeta raíz).

## Desarrollo local

Cualquier servidor estático sirve, por ejemplo:

```bash
python -m http.server 8765
```

y abrir http://localhost:8765
